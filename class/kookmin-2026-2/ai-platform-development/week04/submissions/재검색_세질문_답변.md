## Q1. 행사에 최대 몇 명까지 받을 수 있나요?

**답: 180명** (2026-09-23 변경 승인 반영)

- 변경 전 승인 정원: **160명** (APPROVAL-SPACE-04 / MEMO-04에서 확인)
- 변경 후 승인 정원: **180명** — 2026-09-23 정원 변경 승인
- 홍보 정원(180명, NOTICE-04)과 이제 일치함

**근거**
- CHANGE-SPACE-04(정원변경승인서): "승인 참가 정원을 160명에서 180명으로 변경한다. 이 문서는 APPROVAL-SPACE-04의 참가 정원 조항을 대체한다."
- NOTICE-04(행사안내): 홍보상 모집 정원 180명

**변경 전후 비교**: 승인 정원 160명 → **180명 (+20명)**. 변경 전에는 근거상 정원이 160명이었으나, 승인서 반영 후 180명이 정답이 됨.

## Q2. 대기자를 모두 확정해 준비해도 될까요?

**답: 정원상으로는 가능하나(140 확정 + 40 대기 = 180 = 승인 정원), 자동 전환은 불가. 재원 확인 필요.**

- 확정 140명 + 대기 40명 = 180명 → 승인 정원 180명과 정확히 일치
- 그러나 **다음 조건을 먼저 확인**해야 함:

**근거**
- CLUB-01 제3조(대기자 전환): "승인 정원, 준비 물품, 사용 가능한 재원을 함께 확인한 뒤 신청 순서대로 전환한다. 아직 전환되지 않은 사람을 확정 인원에 미리 더하지 않는다."
- CHANGE-SPACE-04: "신청자 상태를 자동 변경하지 않는다. 지원금·예산 증액을 승인하는 문서는 아니다."
- ACCOUNT-01 제5조: 180명 구매계획 예정비용

**재원 확인 결과 (걸림돌)**
- 180명 구매계획 총 예정비용 **560,000원** (학교지원금 312,000 / 동아리회비 248,000)
- 학교지원금 현재 잔액 **250,000원** < 지원금 예정 312,000원 → **62,000원 부족**
- 동아리회비 잔액 1,843,000원은 충분
- 정원 변경 승인서는 **지원금 증액을 승인하지 않음** → 지원금 부족분은 별도 확보 또는 재원 재배분 필요

**결론**: 정원 상한(180명)은 충족되지만, 대기자 전면 전환은 ① 신청 순서대로 개별 전환 ② 지원금 부족분(62,000원) 해결 후에 진행해야 함. 미리 180명을 확정 인원으로 간주해 물품을 사면 안 됨(CLUB-01 제3조).

## Q3. 외부 대학 학생의 참가가 허용되나요?

**답: 확인 필요 (근거 없음 · 미결)**

- 참가 자격/외부인 참가 조건을 규정한 문서가 **어디에도 없음**
- MEMO-04(운영회의메모): "외부인 참가 조건은 이 회의에서 결정하지 않았다."
- CLUB-01(동아리운영규칙): 신청 상태를 확정·대기·취소로만 구분. 회원/외부인 구분 조항 없음
- 정원 변경 승인서(CHANGE-SPACE-04)도 참가 자격은 다루지 않음(공간·정원만)

**결론**: 외부 대학 학생 참가 허용 여부는 **근거 문서가 존재하지 않아 판단할 수 없음**. 별도 회의 결정 또는 동아리운영규칙 조항 신설이 필요함.
